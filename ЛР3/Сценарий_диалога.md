## Формулировки, распознаваемые правилами

Правил 40: по одному на каждое сочетание. В каждом четыре формулировки,
объединённые `nrel_disjunction`. `X` — название языка: Python, Си, Си++, Java,
JavaScript, Haskell, Пролог, язык ассемблера x86.

| Тип вопроса | Формулировки |
|---|---|
| автор | Кто создал X? · Кто автор X? · Кто разработал X? · Кто создал X |
| год создания | В каком году создан X? · Когда создан X? · Когда появился X? · В каком году создан X |
| реализация | Какая реализация у X? · Какая реализация используется для X? · Чем реализован X? · Какая реализация у X |
| стандарт | Какой стандарт у X? · Каким стандартом описан X? · Какой стандарт действует для X? · Какой стандарт у X |
| сопровождающая организация | Кто сопровождает X? · Какая организация сопровождает X? · Кто поддерживает X? · Кто сопровождает X |

В формулировках с «у X», «для X» и «автор X» склоняемые названия стоят в родительном
падеже: Пролог → Пролога, язык ассемблера x86 → языка ассемблера x86.

Сравнение текста посимвольное: регистр и знак вопроса значимы.
