## Если Ника не ответила

Решатель NIKA изредка теряет уже готовый ответ — задать тот же вопрос ещё раз.
Если перестала отвечать совсем — решатель завис, перезапустить двумя командами выше.

Зависание случается реже, если решателю оставить одно ядро процессора. Для этого рядом
с `docker-compose.yml` положить файл `docker-compose.override.yml`:

```yaml
services:
  problem-solver:
    cpuset: "0"
```

и пересоздать контейнер: `docker compose up -d --no-build problem-solver`, затем
`docker compose restart py-sc-server`. Это не гарантия: с такой настройкой на 283 вопроса
решатель завис 2 раза, без неё на 139 вопросов — 4 раза.

В архиве `vadim_nika.tar.gz` это уже настроено: в папке `nika` лежит готовый `docker-compose.override.yml`. Запуск — см. `README.md` в корне архива.
