# ТиИСПИС, вариант 26 — «Языки программирования»

Всё по лабораторным в одном месте: система NIKA с готовой базой знаний и документы к ЛР1, ЛР2 и ЛР3.

## Скачать

```bash
git clone https://github.com/enterpraizer/nika-lab-v26.git
cd nika-lab-v26
```

Когда появится следующая лабораторная или правки — забрать их одной командой из этой папки:

```bash
git pull
```

После `git pull` перезапустить систему двумя командами из раздела «Остановка и перезапуск».

Готовый проект: база знаний уже лежит внутри, в ней всё для ЛР2 и ЛР3.

## Запуск

```bash
cd nika
docker compose up -d --no-build
```

В первый раз скачиваются образы, потом минуту-две собирается база знаний.
Когда команда завершится, открыть:

- чат — http://localhost:3033
- база знаний — http://localhost:8000

Если раньше NIKA запускалась из другой папки, сначала остановить её там:
`docker compose down`.

## Остановка и перезапуск

```bash
docker compose stop                    # остановить
docker compose start                   # запустить снова
```

Если Ника замолчала или бесконечно «печатает»:

```bash
docker compose restart problem-solver
docker compose restart py-sc-server
```

Обе команды и именно в таком порядке, между ними подождать минуту.

## Как задавать вопросы

- Отправлять **кнопкой с самолётиком**, Enter не работает.
- Текст сравнивается посимвольно: большая буква в начале, знак вопроса в конце.
- Следующий вопрос — после ответа на предыдущий. Нет ответа секунд десять — задать ещё раз.
- Красная панель с `TypeError` при первом открытии чата — закрыть кнопкой «Close».
