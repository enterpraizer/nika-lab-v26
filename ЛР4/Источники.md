# Источники ЛР4

## Источник данных агента

- Рейтинг TIOBE — https://www.tiobe.com/tiobe-index/ (страница, которую разбирает агент;
  на момент проверки — рейтинг за октябрь 2026 года).
- Определение рейтинга TIOBE — https://www.tiobe.com/tiobe-index/programminglanguages_definition/
- Правила обхода сайта — https://www.tiobe.com/robots.txt (запрещён только `/wp-admin/`).

- Методичка «Лабораторный практикум по курсу ТиИСПИС», лабораторная работа №4.

- py-sc-client (шаблоны, работа с sc-памятью по websocket) — https://github.com/ostis-ai/py-sc-client

- Python: `urllib.request` — https://docs.python.org/3/library/urllib.request.html,
